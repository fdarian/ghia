---
'@ghia/native': patch
---

A commit whose layout and structure changes all lie inside a scroller (an overflow `auto` or `scroll` element that holds nothing else the retention excludes) is drawn as a patch of that scroller, whatever it holds (text, boxes with children, a keyed swap of the content with another number of elements; gpui splices the ranges of the scroller into the frame): the scroller is built and laid out again and gpui accepts the patch when nothing outside it moved (`getPatchCounters().relayoutPatches`, `rewrittenRecordings`), where it was a frame built whole. A change outside every scroller is counted as `unpatchable.Structure`, a patch whose box would leak out as `declines.NotContained`. A read of boxes or scroll metrics between the commit and the draw is answered by that patch, prepared ahead of the draw (`Window::prepare_patch`), instead of a layout pass from the window's root, and the draw finishes it without building the scroller again; a mutation or a scroll write after the read discards it, and a patch gpui declines at the read falls back to a pass. Consecutive commits in a scroller are all patches. Needs the contained relayout patch of the zed submodule, which a window opts in to.
