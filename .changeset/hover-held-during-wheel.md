While a wheel is in flight, a build that changed the page (the commit of the rows a virtual list or TanStack Virtual needs for the new offset, a resize, a layout animation) no longer makes the hover under a still pointer follow: `:hover`, `style.hover` and `pointerenter`/`pointerleave` follow when the wheel has been quiet for 500 ms (100 ms after a trackpad lift), as before for a wheel that commits nothing. A pointer that moves, code that scrolls and a change to the page with no wheel in flight follow as they did. The roots of a `div` scroller that a scroll patch moved can be repainted by a hover patch (a tick patch no longer finds their tape moved and rejects it), and a row a scroll patch built for a frame that built other rows is no longer a reason to build the next frame whole.
